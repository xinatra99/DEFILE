# Product

## Platform

web

## Users

Firmware researchers inspecting local binaries, root filesystems and extracted firmware.

## Product Purpose

DEFILE is a self-hosted research workbench for submitting analysis, monitoring
execution, investigating findings, recording triage and exporting reports.

## Operating Context

Full's embedded Alpine interface talks to an authenticated Go service that
runs the Python engine and persists results. Local paths and uploaded evidence
are part of that workflow. Live uses the same interface with an isolated static
adapter and sanitized recordings. It needs no account or analysis backend.
Primary desktop sizes are 1920×1080 and 2560×1440.

## Capabilities and Constraints

Stage 1 acceptance is the regression baseline. Preserve every implemented view,
API contract, report format, database schema, engine algorithm and job protocol.
Moria works locally. Live Ghidra, populated external CVE feeds and genuine AI
inference retain their documented verification limits. No fabricated integrations
or standalone call-graph viewer. No framework migration or new dependencies.
Live preserves those screens with genuine local exploration and explicit recorded
or illustrative labels. It cannot accept uploads, run analysis, mutate published
samples, synchronize feeds or contact AI providers. Session preferences are separate
from Full. Its extension retains the Stage 2A design system.

## Brand Commitments

DEFILE, English-only authored interface, preserved evidence encoding and licensing.
The parent portfolio is a read-only visual reference: minimalist monochrome,
Apple-inspired restraint, neutral surfaces and precise technical presentation.

## Product Principles

- Preserve the real research workflow and expose complete technical values.
- Make primary actions easy to find and state changes clear.
- Spend desktop space on readable evidence and useful workspace capacity.
- Keep all work local to DEFILE; do not alter or publish the portfolio.
